# Shared Cycle catalogue dependencies

The reviewed sources establish that Joker sets follow an eligible PR set and
are conditional on daily readiness. The current frozen block vocabulary has no
primitive for a conditional, open-ended load progression with a typed stopping
policy. No `joker_*` component is emitted until that generic primitive exists;
an empty executable block would be a placeholder.

Beyond's incremental warm-up, FSL, SSL, Boring But Strong and Widowmaker
prescriptions depend on the current session's work-set percentages or on a
template-specific top/first/second-set relation. The frozen load vocabulary can
express only literal TM/1RM percentages, fixed load, bodyweight and unloaded
work. These components are therefore intentionally absent rather than encoded
with invented percentages.

Only the reviewed Original deload is emitted. The indexed Beyond deload options
remain absent because their exact prescriptions are not reviewed in the local
audit.
