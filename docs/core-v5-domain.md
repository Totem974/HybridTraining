# Core v5 domain model

Program identity separates concept, revision, blueprint, historical origin,
source edition, and executed ruleset generation. Library entries also carry type,
documentation and implementation status, product availability, references,
frequency, goals, level, equipment, capabilities, compatibility, and restrictions.

`MovementId` is an extensible stable value. The historic squat, bench press,
deadlift, and overhead press IDs remain available without closing the model to
cleans, front squats, variants, assistance movements, bodyweight work, or unloaded
activities.

Blocks independently describe structural type, ruleset role, generation, source
edition, and typed protocol purpose. Prescriptions share a common contract for
sets/reps/load, total reps, duration, distance, rounds, completion, and qualitative
goals. Their calculated target and actual result are always separate.

Generated plans retain programming-block, cycle, week, session, and calendar
coordinates; rule provenance; planned events; transitions; and amendable TM
decisions. Completed work and actual results are immutable history.
