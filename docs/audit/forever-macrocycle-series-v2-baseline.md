## Historical equivalence anchor

The historical Forever reference is
`test/fixtures/core-v5/forever-original-fsl-2l1a.golden.json`. It is generated by
`test/unit/features/programs/v2/reference_plan_goldens_test.dart` with
`CanonicalGenerationBlueprint.foreverOriginalFsl`.

The v4 migration and generic compiler must leave this fixture unchanged, or
demonstrate functional equivalence explicitly if byte stability cannot be
preserved. Existing snapshots are append-only for this work.

  standalone program identifier or a finite `ForeverProgramSeries`.

- 2L/2A and 3L/2A remain structural `needsReview` entries until complete sources
  are reviewed.

  transport or UI layers.
