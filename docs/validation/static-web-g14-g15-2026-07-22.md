## Résultat

La page `/cycle/` est produite en HTML/CSS/TypeScript, sans backend ni appel
réseau métier. Le moteur Dart pur, le catalogue et IndexedDB restent locaux au
navigateur. Flutter Web et `/forever/` sont conservés ; aucune bascule de
production ni aucun push n'a été effectué.

| Contrôle | Résultat |

| Parité Cycle native/JavaScript | 23/23, aucune différence |
| Golden Forever native/JavaScript | 1/1, aucune différence |
| Contrats JSON | aucune défaillance |
| Tests Dart moteur / bridge | 4/4 et 6/6 |
| Tests Flutter | 402 réussis |
| Tests TypeScript | 20/20 |
| Playwright Chromium | 14/14 |
| Playwright WebKit | smoke 1/1 |
| Responsive | 1440, 390 et 320 px |
| Réseau externe | bloqué et vérifié dans les E2E |
| Builds | Vite et Flutter Web release réussis |

Les scénarios navigateur couvrent Standard, BBB, Two Days, rep-max avec
répétitions distinctes, options, plaques, persistance, import/export, FR/EN et
les trois largeurs de référence. Les archives de la source d'inspiration ont
été auditées en lecture seule ; aucun code, actif, nom de marque ou police n'a
été repris.

## Tailles finales

Mesure sur les artefacts release, longueur brute puis gzip indépendant.

| Artefact Web statique | Brut | Gzip |
| --- | ---: | ---: |
| Bridge Dart JavaScript | 179 023 o | 55 357 o |
| JavaScript UI | 19 230 o | 6 830 o |
| CSS | 11 257 o | 2 883 o |
| `catalog.bundle.json` | 238 913 o | 24 258 o |
| HTML `/cycle/` | 4 355 o | ~1 160 o |
| **Chemin critique cumulé** | **452 778 o** | **~90 488 o** |

Le dossier statique complet pèse 1 362 427 octets bruts. Il contient aussi
`catalog.db` pour la preuve du pipeline, mais le navigateur charge le bundle
JSON et non SQLite.

À titre de comparaison, le `main.dart.js` Flutter actuel pèse 3 507 216 octets
bruts (991 611 octets gzip) et son dossier `build/web` complet 44 930 473
octets bruts. Le chemin critique statique est donc environ 87 % plus petit que
le seul JavaScript Flutter en brut et 91 % plus petit en gzip. Cette comparaison
n'est pas une mesure réseau parfaite : le dossier Flutter comprend des moteurs
de rendu et actifs qui ne sont pas nécessairement tous téléchargés.

## Limites et cutover

- Firefox n'a pas été ajouté ; Chromium et WebKit constituent la couverture
  multi-navigateurs de cette phase.
- Les captures 1440/390/320 sont des preuves locales ; la comparaison humaine
  finale reste requise avant une bascule.
- Flutter Web, sqflite Web, Android et l'interface Forever restent intacts.
- Le plan de bascule est documenté dans
  `docs/architecture/static-web-cutover.md` et nécessite une autorisation
  distincte.
