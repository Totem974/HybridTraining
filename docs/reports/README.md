# Rapports finaux des travaux

Ce dossier conserve un rapport final durable pour chaque tâche livrée par un
commit. Il complète l'historique Git sans remplacer la documentation détaillée
du produit, de l'architecture ou des audits.

## Convention

- un fichier par tâche et par commit logique ;
- nom : `AAAA-MM-JJ-<sujet-court>.md` ;
- contenu minimal : objectif, périmètre, résultat, fichiers principaux,
  validations, limites et état Git ;
- aucune donnée personnelle, preuve binaire, capture ou configuration locale ;
- le hash Git reste porté par le commit qui ajoute le rapport, afin d'éviter une
  référence circulaire dans le fichier lui-même.
