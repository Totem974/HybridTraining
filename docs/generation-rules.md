# Rules by generation

## Powerlifting Standard

Three work weeks use the selected 5/3/1 pattern and week four is deload. Four-day
planning fixes one main movement per day; three-day planning rotates four movements
through selected weekdays. End-of-cycle TM decisions are explicit.

## Beyond

Two distinct three-week cycles are followed by deload. The second cycle uses the
new TM from the checkpoint after cycle one. Three-day frequency extends calendar
duration; it does not alter programming-week identity. Beyond is never represented
as Leader/Anchor.

## Forever

The executable reference is Original + FSL: Leader 1, Leader 2, typed 7th Week
Deload, Anchor, then typed 7th Week TM Test. This is 11 programming weeks. Deload,
TM Test, and PR Test are distinct protocol purposes.

## Beginner Prep School

One staged three-week cycle alternates A/B across three days. Each session has two
main movements using 5’s Pro and FSL/SSL selected by the explicit 85%/90% TM ratio,
plus executable warm-up, jumps, assistance, and conditioning. Progression remains
an explicit post-cycle decision.

Every automated rule carries an exact local source reference. No missing rule is
inferred from memory.
